# Project: Depths

A procedural roguelike dungeon crawler in Godot 4.7 (GDScript).

## About me
I'm a first-year CS student learning game development. I want to
understand every system I build, because I'll need to explain it in interviews.

## Rules for you
- Explain concepts before giving code.
- Don't write whole systems for me. Give hints or small snippets first.
- When I share code, review it and point out bugs and bad habits.
- Use signals instead of direct node references.
- Keep data (damage, speed) in exported variables or Resources, not hardcoded.
- Keep scripts small and focused on one job.

## Project structure
- scenes/    scene files (.tscn)
- scripts/   GDScript files
- resources/ custom Resources (items, enemy data)
- assets/    art and sound
